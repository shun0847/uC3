１．サンプルプログラムの概要
------------------------------------------------------------------------------
MQTTクライアントの動作サンプルです。シェルのコマンドから
MQTTのブローカーへ接続、データのpublish, subscribeを行えます。

MQTTのコマンドは以下のドキュメントを参照してください。
(パッケージをC:\uC3にインストールした場合を例とします)
    C:\uC3\Document\MQTT_SampleGuide.pdf
    C:\uC3\Document\MQTT_UserManual.pdf

・シリアル通信
  ホストPCのターミナルソフトの設定は、次のようにします。
  ┌───────────────────────┐
  │Baud rate  Data  Parity  Stop  Flow control   │
  │---------  ----  ------  ----  ------------   │
  │ 115200    8bit   none   1bit     なし        │
  └───────────────────────┘

------------------------------------------------------------------------------
チュートリアルガイドの「シングルコアuNet3サンプル」と同様となります。
そちらを参考にビルド・デバッグ実行を行ってください。
